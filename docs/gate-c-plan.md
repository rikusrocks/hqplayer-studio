# Gate C 测试计划 —— 在真实 HQPlayer 上验证写命令

> 状态：**已完成**（2026-11-10，用户在 HQPlayer Desktop 6 / engine 6.1.0 上运行 `hqp-gatec` v0.1.0）。结果见第 10 节。
> 目标引擎：用户的 HQPlayer Desktop 6，engine 6.1.0，Windows（Gate A/B 只读探测已完成，见 `protocol-capabilities.md`）。

## 1. 目的

只读阶段已确认 Studio 能稳定读取 HQPlayer。Gate C 要回答的是 **Studio 能否安全地控制 HQPlayer**：

| 要确认的问题                                                              | 结果决定 Studio 的哪个功能                 |
| ------------------------------------------------------------------------- | ------------------------------------------ |
| `Pause` 是切换还是幂等？`Play` 能否从暂停恢复？                           | 播放/暂停按钮                              |
| `Seek position=` 的单位与“可听位置”的关系（4.4 s 输出延迟）               | 进度条拖动                                 |
| `Next` / `Previous` 行为（`Previous` 在曲中是否先回到开头）               | 上一首/下一首                              |
| `PlaylistAdd` 应传原生路径还是 `file://` 形式；中文/日文/空格路径是否可用 | 播放专辑/歌曲/播放列表                     |
| `queued` / `clear` 参数语义；`SelectTrack` / `PlaylistRemove` 是否 1 基   | 立即播放、下一首播放、加入队列、从队列删除 |
| PCM → DSF 切换、同一专辑两首连播是否无缝                                  | 专辑播放与 Gapless 提示                    |
| 自动恢复原播放列表是否可靠                                                | 以后 “接管/恢复” 功能                      |

## 2. 安全原则

1. **你在场、逐步确认**：每一步都要你按回车才执行；任何时候按 `q` 中止，`s` 跳过。
2. **不碰 DSP 与输出设置**：不发送 `SetMode` / `SetFilter` / `SetShaping` / `SetRate` / `SetConvolution` / `MatrixSetProfile` / `ConfigurationLoad` / `Reset`。输出保持 SDM DSD512。
3. **默认不改音量**：`Volume` 只有在你单独同意时才测试，而且只会设置为当前值（-6.02 dB），不会调大。
4. **先备份再修改播放列表**：开始前读取你当前的 HQPlayer 播放列表（目前 52 首），在本机保存两份备份：
   - `hqp-gatec-backup-日期.m3u8`：HQPlayer 自己就能打开的标准播放列表（自动恢复失败时的保底方案）；
   - `hqp-gatec-backup-日期.json`：工具自动恢复用。
     两份备份含真实路径，**只留在你的电脑上，不要发回**。
5. **结束必恢复**：无论成功、跳过还是中止，最后都尝试把播放列表恢复原样（相同曲目与顺序、选中原曲目、**不自动播放**），并核对恢复结果。
6. **只用测试素材**：装载测试只使用你指定的小测试文件夹，不会把测试曲目写进你保存的 HQPlayer 播放列表。
7. **独立工具**：使用单独的 `hqp-gatec.exe`，与只读的 `hqp-probe.exe` 分开；Studio 应用本身的写功能在测试通过前保持禁用。
8. **报告脱敏**：发回给开发者的 `hqp-gatec-report-*.json` 与只读报告一样脱敏（无曲名、路径、播放列表名）。

## 3. 你需要准备的东西（约 20 分钟）

- 一个**测试文件夹**，例如 `D:\HQPS 测试\テスト アルバム\`（路径里最好同时有中文/日文和空格），放入：
  - **同一张专辑里连续的 3 首 PCM 曲目**（FLAC 即可；最好是曲间无缝的专辑，例如现场或古典专辑），复制过来即可；
  - **1 个 DSF 文件**（如果有；没有就跳过 DSD 项）。
- 放大器音量调到适中；测试中会短暂播放、跳转。
- HQPlayer 正常打开即可（播放或停止都行）。

## 5. 不在本次范围

DSP / 输出 / 设备 / 卷积 / Matrix / 配置切换；`PlaylistSave` / `PlaylistDelete` / `PlaylistUpload`；收藏；`LibraryLoad`；`Reset`；`SessionAuthentication`。

## 6. 结果怎么用

- 工具生成脱敏报告 `hqp-gatec-report-*.json`，你发回后，逐项更新 `protocol-capabilities.md` 与运行时能力矩阵（`untested` → `confirmed` / `unsupported`）。
- 只有通过的能力才会在 Studio 中出现；并且新增总开关 **“允许 Studio 控制 HQPlayer”**（默认关闭），打开前 Studio 仍只读。
- 失败或行为不符的项目会保持禁用，并在设置页说明原因。

## 7. 中止与故障处理

- 按 `q`：立即停止后续步骤 → `Stop` → 进入 C4 恢复。
- 连接断开或命令超时：不重试写命令；提示你检查 HQPlayer，然后尝试恢复。
- 自动恢复核对失败：工具会提示你在 HQPlayer 中打开 `hqp-gatec-backup-*.m3u8`（文件 → 打开播放列表）手动恢复。

## 9. 实现说明（2026-11-10）

- 代码：`scripts/hqp-probe/src/gatec/`（`session.ts` 命令白名单与音量守卫，`run.ts` 步骤，`files.ts` 备份/恢复与路径标签）。
- 白名单之外的命令（DSP、输出、配置、`PlaylistSave` 等）在发出前即被拒绝；`Volume` 只能设为开始时读到的原值。
- 报告中不含路径、文件名、曲名：测试文件记为 T1/T2/T3/DSD，原播放列表条目记为 `backup#n`；HQPlayer 返回的错误文本会去除路径与已知文件名。
- 恢复：优先用原生路径（与 C2.2 结果一致）；若原生路径被拒而 `file://` 形式可用，则改用后者；恢复后逐条核对。
- 验证：自动化测试 11 项（含中止恢复、原生路径被拒时的回退、无测试文件夹时不改播放列表、命令白名单与音量守卫、报告无隐私数据）；
  另用真实编译出的 `hqp-gatec` 可执行文件对有状态的模拟引擎完整跑了一遍（29 个交互回答，6/6 恢复）。
  模拟引擎的行为是虚构的，**不能**当作 HQPlayer 的证据——真实结果只来自你运行后发回的报告。

## 10. 结果（2026-11-10）

| 步骤                      | 结果   | 关键观察                                                                |
| ------------------------- | ------ | ----------------------------------------------------------------------- |

由此在 Studio 中的实现（v0.1.4）：新增“允许 Studio 控制 HQPlayer”开关（默认关闭，立即生效）；只开放上表通过的命令；
